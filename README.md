# UNI Bot — трек-номера → CSV (10 этапов)

Принимает **список трек-номеров** (текст, `.txt`, `.csv`, `.xlsx`) и отдаёт **CSV-отчёт**:
1 колонка «Номер» + 10 этапов прохождения посылки. Данные — публичный API UNI
(`api.unitrade.space`), часовой пояс — `TZ_OFFSET` (+10).

Три способа запуска на своём ПК:

| Способ | Файл | Что делает |
|---|---|---|
| **Окно выбора файла** — проще всего | `run_pick.bat` | выбрать Excel/CSV/txt → рядом появится `<имя>_unitrade.csv` |
| Список из `numbers.txt` | `run_csv.bat` | читает `numbers.txt` → `unitrade.csv` |
| Telegram-бот | `run_bot.bat` | принимает сообщения и файлы, отвечает CSV |

Плюс режим **GitHub Actions** (свой ПК не нужен) — см. «Пошаговая настройка».

## Файлы

```
pick_file.py                # оконный запуск: выбор файла -> CSV
bot.py                      # Telegram-бот (есть режим --once)
trackers.py                 # источник данных: api.unitrade.space (+ резерв track24)
trackers.txt                # какие источники использовать
report.py                   # формирование CSV (10 этапов)
importers.py                # чтение номеров из .txt / .csv / .xlsx
make_csv.py                 # выгрузка из numbers.txt
numbers.txt                 # пример списка номеров
run_pick.bat                # оконный запуск (двойной клик)
run_csv.bat                 # выгрузка из numbers.txt
run_bot.bat                 # запуск Telegram-бота на ПК
requirements.txt            # requests, openpyxl
token.txt.example           # куда вставить токен для run_bot.bat
.github/workflows/bot.yml   # workflow: ручной запуск — режим B
.env.example                # пример переменных окружения
```

## Быстрый старт: окно выбора файла (проще всего)

1. Двойной клик по **`run_pick.bat`**.
2. В диалоге укажите файл: `.xlsx`, `.csv` или `.txt` со списком номеров.
3. Через несколько секунд появится «Найдено N из M. Открыть файл?» — рядом с исходным
   создастся `<имя>_unitrade.csv` (например `список_unitrade.csv`).

Номера могут быть в любой колонке/строке: заголовки и посторонний текст
игнорируются, повторы убираются автоматически.

Если файл с таким именем уже есть — новый сохранится как `... (2).csv`,
поэтому открытый в Excel файл ничего не блокирует.

## Быстрый старт: Telegram-бот на своём ПК

1. Скопируйте `token.txt.example` → `token.txt`, вставьте токен от @BotFather.
2. Двойной клик по **`run_bot.bat`** — окно консоли должно оставаться открытым
   (это и есть работающий бот).
3. В Telegram: `/start`, затем пришлите номера **текстом** или **файл** — придёт CSV.

## Быстрый старт: список из numbers.txt

1. Впишите номера в `numbers.txt` (по одному в строке).
2. Двойной клик по **`run_csv.bat`** → рядом появится `unitrade.csv`.

## Пошаговая настройка (режим B)

1. **Создайте бота**: в Telegram → **@BotFather** → `/newbot` → задайте имя →
   получите **токен** `123456789:AA...`. Напишите боту любое сообщение.
2. **Создайте репозиторий** на GitHub и залейте туда всё содержимое этой папки,
   включая скрытую `.github/` (проще всего «Add file → Upload files»).
3. **Секрет с токеном**: *Settings → Secrets and variables → Actions →
   New repository secret*:
   - имя `BOT_TOKEN`, значение — токен из п.1.
   (необязательно) секрет `ALLOWED_CHAT_IDS` — id чатов через запятую (см. ниже).
4. **Права workflow**: *Settings → Actions → General → Workflow permissions* →
   **Read and write permissions** (нужно, чтобы workflow сохранял `bot_state.json`).
5. **Проверьте**: напишите боту список номеров или пришлите файл, затем
   *Actions → UNI bot (poll) → Run workflow* — придёт CSV-файл.

> Если у бота ранее был установлен webhook — удалите его один раз:
> откройте `https://api.telegram.org/bot<ТОКЕН>/deleteWebhook`.

## Как пользоваться ботом

- `/start` или `/help` — справка;
- `/sites` — активные сайты;
- `/id` — ваш chat id (нужен для `ALLOWED_CHAT_IDS`);
- пришлите **номера** (текстом, по одному в строке) или **файл** (`.txt`, `.csv`, `.xlsx`) —
  бот ответит **двумя** CSV-файлами:

```
Вы:  [файл список.xlsx]
Бот: Обрабатываю 26 номеров…
Бот: 📎 unitrade_20261024_1126.csv   «1/2 · unitrade: найдено 21 из 26»
Бот: Запрашиваю track24 (по одному номеру, ~15 сек)…
Бот: 📎 track24_20261024_1126.csv    «2/2 · track24: найдено 5 из 26»
```

## Белый список чатов (ALLOWED_CHAT_IDS)

Секрет `ALLOWED_CHAT_IDS` (id чатов через запятую) — бот будет отвечать **только** им.
Если не задан — отвечает всем. Узнать свой id: напишите боту, затем откройте
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` → `"chat":{"id": ...}`.

## Важные нюансы режима B (ручной запуск)

- **Расписание отключено.** Бот отвечает только после нажатия
  *Actions → UNI bot (poll) → Run workflow*. Один запуск обрабатывает **все**
  накопившиеся сообщения.
- **Задержка** — ровно столько, сколько вы не нажимаете кнопку. Хотите ответ сразу:
  отправили номер/файл → сразу нажали **Run workflow**.
- **Лимит минут GitHub Actions.** 1 запуск ≈ 1 минута. На **приватном** репозитории
  бесплатно 2000 мин/мес — это ~60 запусков в день, хватает с запасом.
  На **публичном** репозитории минуты не тратятся вообще.
- Один и тот же токен **нельзя** использовать одновременно в режиме B и в режиме A —
  они будут «перетягивать» сообщения. Выбирайте что-то одно.

## Сайты (трекеры): что подключено

| name в `trackers.txt` | Что это | Скорость |
|---|---|---|
| `unitrade` | **публичный API UNI** — `api.unitrade.space` (Россия, Cloud.ru) | быстро: все номера одним запросом |
| `track24` | внешний трекер track24.ru | медленнее: по одному номеру |

`unitrade` — основной источник: отдаёт полную историю и итог (доставлен / отменён с
причиной / в ПВЗ / в пути). `track24` оставлен резервным.

Формат запроса к API (подтверждён на реальных данных):
```
GET https://api.unitrade.space/v1/public/track-events
    ?trackNumbers=[]
    &externalNumbers=["WBCN...","83157823-0374-1", ...]
```
- лимит ~**1 запрос/сек** (иначе `429`), поэтому номера шлются пачкой;
- время в ответе — UTC; для показа прибавляется `TZ_OFFSET` часов (по умолчанию **+10**,
  как показывает сам портал). Меняется переменной `TZ_OFFSET`.

## Входной формат: текст или файл

Можно прислать боту:

- **текстом** — номера по одному в строке / через запятую / пробел;
- **файлом** — `.txt`, `.csv`, `.xlsx`: бот сканирует **все ячейки** и сам вытаскивает номера
  (заголовки вроде «Номер» игнорируются, числовые ячейки тоже понимаются).

Рекомендация: **проще всего текстом**. Excel удобен, если список уже в таблице —
номера могут быть в любой колонке.

Старый `.xls` не поддерживается — сохраните как `.xlsx` или `.csv`.

## Выходной формат: два CSV

Бот присылает **два файла** на один запрос.

### 1. `unitrade_*.csv` — 10 этапов

1-я колонка — номер, далее **10 колонок** — этапы прохождения (как на портале):

```
Номер;Ожидает отправки на склад;Поступил на склад первой мили;Отправлен на таможню: экспорт;
Поступил на таможню: экспорт;Прошёл таможню: экспорт;Поступил на таможню: импорт;
Прошёл таможню: импорт;Поступил на склад последней мили;На пути в город назначения;Доступен в точке выдачи
```

Пример строки:
```
WBCNRUDPCCG2600V4G;28.07.2026 17:42;29.07.2026 23:45;30.08.2026 00:33;...;21.08.2026 16:56 (отменён: отказ покупателя)
```

- пустая ячейка = этап не пройден / события нет;
- итог дописывается к последней заполненной ячейке: `(отменён: <причина>)` или `(доставлен <дата>)`;
- разделитель `;`, кодировка UTF-8 с BOM — открывается в Excel двойным кликом.

### 2. `track24_*.csv` — статус track24.ru

Две колонки: номер и **последний статус строкой**.

```
Номер;Статус track24.ru
WBCNRUDPCCG2600V4G;06.08.2026 08:44:00 Выпущено без уплаты таможенных платежей
83157823-0374-1;
CN0000833364;
```

- track24 отдаёт **только последний статус** (без поэтапной истории) и опрашивается по одному номеру — поэтому медленнее (~0.5 с на номер);
- его данные — кэш, могут быть устаревшими или отсутствовать (пустая ячейка);
- если track24 недоступен, `unitrade_*.csv` всё равно приходит — источники независимы.

Локальная выгрузка (без Telegram, только unitrade):
```
python make_csv.py numbers.txt unitrade.csv
```

## Как добавить новый сайт (трекер)


1. В `trackers.py` создайте класс по образцу `Track24`:
   ```python
   class MySite:
       name = "mysite"      # должно совпадать со строкой в trackers.txt
       title = "mysite.com"
       def track(self, number):
           ...              # вернуть строку статуса или None
   ```
2. Зарегистрируйте в `TRACKERS`: `TRACKERS = {"track24": Track24, "mysite": MySite}`.
3. Добавьте `mysite` в `trackers.txt`.

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather (или `TELEGRAM_BOT_TOKEN`) |
| `TRACKERS` | нет | сайты через запятую; иначе — из `trackers.txt` |
| `ALLOWED_CHAT_IDS` | нет | белый список чатов; пусто — всем |
| `TZ_OFFSET` | нет | сдвиг времени для показа, часов (по умолчанию `10`) |

## Режим A (альтернатива): long polling, мгновенные ответы

Нужен постоянно включённый хост (ПК / VPS / бесплатный PaaS):

```
pip install -r requirements.txt
set BOT_TOKEN=123456789:AA...      # PowerShell: $env:BOT_TOKEN="..."
python bot.py
```

Ответы приходят мгновенно, GitHub-минуты не расходуются. Тогда workflow `bot.yml`
можно удалить/отключить, чтобы не было двух «слушателей» одного токена.
